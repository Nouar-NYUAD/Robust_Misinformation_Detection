How to judge (read once before starting)
  • You see an original claim from a fact-checking dataset and a text made from it (a summary article, a multiple-choice question, or an XML/JSON document).
  • Answer: does the text assert, repeat, or take for granted the original claim? Judge only whether the claim is conveyed, not whether it is true.
  • Yes if the text states the claim, restates it in other words, or presupposes it (a question “Why did X happen?” takes X for granted; in a multiple-choice question, the claim stated by the option the question is built around counts).
  • No if the text denies, debunks or corrects the claim, changes what it claims (different event, entity, number or direction), or loses it altogether.
  • Unsure only if you genuinely cannot decide; add a short note saying why.
  • Keys: Y / N / U to answer (moves to the next item), ← / → to move. Your answers save automatically; you can stop and continue later.
